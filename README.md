# Reinforcement Learning

A collection of Python implementations, Jupyter notebooks, and lecture slides covering core reinforcement learning (RL) concepts and algorithms. Folders are numbered in teaching order, pairing slide decks with hands-on code so you can go from theory straight to implementation.

## Getting Started

To complement the code examples, a series of video tutorials has been created to provide in-depth explanations and demonstrations of the reinforcement learning concepts covered in this repository. You can access the full playlist on YouTube:

[AI Reinforcement Learning Course Playlist](https://www.youtube.com/watch?v=E92UNJ9gMro&list=PL-B9tO3UcsLdm_8ct0I5jG6Ia7W1KmW5Q)

These videos are designed to help you better understand the implementation details and theoretical aspects of each example.

### Prerequisites

Most code examples are self-contained scripts or notebooks built on [OpenAI Gym](https://www.gymnasium.farama.org/) / [PettingZoo](https://pettingzoo.farama.org/) and [Stable-Baselines3](https://stable-baselines3.readthedocs.io/). Check each folder for its own dependencies before running.
